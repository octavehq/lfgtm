# audit: task method

Create a coverage ledger by entity ID/type/check: inventoried, full detail read, source reviewed, sampled, excluded, failed, or unknown. Exhaust pagination for population claims. Run structural field/link/reference checks over every eligible full object. Declare the scope of semantic review separately. A failed/truncated read is a coverage gap, not proof that customer content is missing.

For strategic review, use CRM to select recent won, lost, no-decision, expansion and renewal examples relevant to the requested offerings/motions; inspect their calls and related findings. State the selection window and representation limits. Compare observed buyer roles, problems, alternatives, decision criteria and outcomes with library narratives. Label approved strategy, field-supported pattern, and expansion hypothesis separately. Ask the operator only for unresolved strategic intent or unavailable results, then incorporate the answer. Do not discard a new segment merely because it has no historical wins.

Determine commercial identity separately from narrative grouping. Check independent contract/renewal, price/entitlement, delivery scope, deployment/use, service obligation, purchase path and workflow; also inspect buyer, meeting and quota structure where applicable. Shared buyer or quota does not by itself make an offering a feature. Recommend grouping narratives when appropriate without collapsing legitimate catalog entities. Before any collapse, present the specific duplicated identity/context problem and the retained commercial distinctions. Do not migrate based solely on a failed sales-led heuristic.

Treat uniform weights, missing negative questions and other static shapes as review prompts, not demonstrated score defects. Read the actual scoring/configuration contract and run representative qualification cases before asserting score effects; refer unresolved calibration to qual-doctor.

For migration, inventory full source/destination entities, questions, links, Motions/Playbooks/cells and dependent agent configuration. Build an exact mapping and preservation checklist; snapshot revisions. Verify that supported write tools exist for every required operation. Create/update destinations, read them back, rewire consumers through supported APIs, and verify all references. Run representative generation and qualification checks before archiving sources. If a required write is unsupported or a check fails, preserve the source, record the pending step and stop dependent mutation. Do not report a complete migration from list_agents alone. Recover only within verified scope, preserving unrelated concurrent changes.

Report separately: unresolved critical blockers; structural checks passed/eligible; semantic objects reviewed/eligible; evidence freshness/coverage; runtime cases passed/tested; and intentional exceptions. Mark readiness as blocked for the affected use, ready with stated limitations, or verified for the tested scope. Untested is not passed. Positive findings cannot cancel a critical blocker. Do not reward entity counts/type presence without a demonstrated need. Keep any experimental numeric score secondary, labeled uncalibrated, and unable to override blockers.
