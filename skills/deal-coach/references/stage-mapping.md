# deal-coach: task method

### Coaching focus from buyer evidence
Read [gtm-context.md](../../shared/gtm-context.md), [evidence-and-inputs.md](../../shared/evidence-and-inputs.md), and [output-readiness.md](../../shared/output-readiness.md) for the selected deal. Use the workspace's own methodology (the active Motion's, or one the user supplied) and follow [information principles #18](../../shared/information-principles.md#reading-calls-and-deals): R/E/C framing appears only when it is on file or the user asks for it, and with no methodology on file the plan carries no framework section. Load [analytics-contract.md](../../shared/analytics-contract.md) only for an actual benchmark or cohort comparison.

Resolve the opportunity and retrieve its current CRM stage, participants, commitments, and calls. Read a relevant persona cell for each material decision-maker. Ask grouped questions for missing recent decisions, commercial policy, POC results, or unrecorded constraints; continue supported coaching and incorporate the answers with provenance.

Report three separate items: CRM stage; demonstrated buyer readiness; recommended coaching focus. Do not assign confidence percentages from fuzzy CRM-stage names. For each buyer readiness claim record the commitment or behavior, its source/date, contradictory evidence, and the remaining test. Confidence is supported, tentative, or insufficient evidence, with a reason; it is not a calculated probability.

Under R/E/C framing: Resonate concerns confirmation of a consequential problem and relevance; Elevate concerns the buying group's comparative case and decision criteria; Compel concerns an agreed reason/timing to act and a credible path through approval and execution. Pricing interest alone does not establish Compel. Different participants may have different unresolved decisions. An explicit stage flag chooses the coaching focus while preserving missing prerequisites.

Choose goals from the actual gaps, not a fixed quota. Each goal contains recipient, desired commitment, relevant argument/proof, exact talk track, diagnostic question, and an observable success condition. Include a rehearsal based on the real objection and feedback grounded in the customer's method. A generic practice request without a deal does not trigger a routing loop to train.
