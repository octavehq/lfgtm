# Scale filter derivation
For every recommended external filter provide: selected ICP criterion → source → observable field/operator/value → direct or proxy → expected exclusion effect → remaining qualification check. Derive values from this customer's context and user constraints; never seed software, funding, headcount-growth, technology, or date defaults as universal criteria.

Use “derived from your current ICP” unless actual outcome evidence was collected. “Based on successful deals” requires a defined opportunity cohort, time window, deduplication, relevant losses/pursuit mix, and uncertainty under the analytics contract. Do not create a second arbitrary weighted score that contradicts the configured qualification model. Validate provider-specific field/operator syntax before labeling filters copy-ready; otherwise label the mapping as a specification requiring translation.
