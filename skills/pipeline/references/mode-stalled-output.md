# Stalled opportunity

Read [the opportunity method](task-method.md).

For each plausible blocker show supporting and contrary evidence, last verified buyer commitment, agreed next date, owner, and next discriminating test. Separate procurement work, product fit, delivery capacity, funding, agreed delay, and weak engagement. Retrieve enough history before asserting silence. Select action timing from buyer agreements and champion strategy; do not escalate after an arbitrary week. Include hold/nurture, recovery, and no-fit when supported. Draft the actual next message or document request, with a condition for escalation and a review date.
