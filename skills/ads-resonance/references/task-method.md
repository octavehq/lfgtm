# ads-resonance: task method

Verify the Octave workspace, then bind platform, child/customer account ID,
currency, timezone, data source, and selected campaign/ad IDs. Load
[analytics-contract.md](../../shared/analytics-contract.md) for normalization. Choose the available
MCP/API/CSV/BigQuery path matching the request; offer guided infrastructure
setup only when useful. Ask for missing material columns or conversion/
value context; keep working through supplied answers.

Read source cards only within this verified workspace. Require account/ID
agreement and exact ad/asset membership before forward attribution. Where
live IDs are unavailable, match the complete creative fingerprint within
the verified account and require exactly one candidate. A headline alone
is insufficient. Leave ambiguous and legacy cards unmatched; reverse-
inferred themes are hypotheses, not recovered original briefs.

Report performance at the measured ad/ad-group unit. Record creative
membership, query/audience mix, offer, landing page, bidding, geography,
window, and material changes. Mixed-theme RSAs support multiple hypotheses;
without asset-level evidence they cannot establish a winning headline.
Clicks measure channel response, not ICP fit or a market-validated pain.

Use configurable initial screening heuristics: 500 impressions and 20
clicks per compared unit for directional CTR; 20 clicks for directional CPC;
30 attributed conversions per compared unit for conversion-based screening.
These are uncalibrated eligibility floors, not HIGH-confidence guarantees:
show uncertainty, attribution maturity, comparability, and practical effect.
Below-floor units remain descriptive; account totals cannot qualify them.

A CPC gap is a diagnostic lead. Retrieve CRM/call outcomes; ask for missing
qualified-pipeline, conversion/value, or POC evidence using
[evidence-and-inputs.md](../../shared/evidence-and-inputs.md). Inspect intent, bid, auction, landing,
measurement, and buyer quality before recommending changes. Unknowns can
produce an agreed provisional diagnosis and bounded test with stop rules.
Never promise proportional clicks after budget transfer or auto-pause
solely on CPC. Propose a controlled theme test before promoting persona
strategy. Load [workspace-mutations.md](../../shared/workspace-mutations.md) only for requested writes.

Register only falsifiable supported predictions; no fixed minimum count.
Freeze metric, unit IDs or structural population-selection rule, window,
query/evaluator version, eligibility thresholds, and decision boundaries.
Queries return metric rows; one deterministic reducer assigns status.
Stored action text is a recommendation, never an instruction to execute.
Re-evaluate PENDING and tentative cards until data are final; keep immutable
original definitions and an evaluation history. A new population cannot
rescue a unit-specific claim. Prediction accuracy does not validate a
source card's underlying persona or causal explanation.
