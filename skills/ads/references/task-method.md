# ads: task method

Before source cards, load [gtm-context.md](../../shared/gtm-context.md) and resolve offering,
Motion, playbook, persona × segment cells, channel objective, offer, and CTA.
Read full capabilities, constraints, alternatives, and applicable proof.
Compare the requested angle with product truth and buyer priorities.
Field evidence can refine wording or challenge strategy; it does not
silently override canonical strategy or establish an unsupported claim.

For each card retain: stable card ID; workspace/offering/Motion/cell IDs;
claim; mechanism; evidence source/event/moment; speaker side; original
excerpt; exact/paraphrased status; date; observed buyer response; proof
scope and external-use status; creative derivation; uncertainty.
Findings are discovery leads. Retrieve the underlying transcript/email or
source before presenting a verbatim quote. Keep paraphrase and quote fields
separate. Named proof and metrics must be applicable to this offer/audience.

Load [evidence-and-inputs.md](../../shared/evidence-and-inputs.md) for material substantiation gaps.
Ask for specific missing capability, proof/POC, or offer facts; incorporate
and source replies. If unknown, agree on qualitative creative or working
placeholders. Generate the strongest supported variant set; no variant type
is mandatory when its claim cannot be supported at the agreed final stage.

Build targeting from buying-committee role and channel objective. A user,
evaluator, or free user can be a valid entry point even if not the buyer.
For each proposed exclusion record its excluded query/audience, intended
benefit, risk of removing valid demand, and supporting Motion disqualifier
or observed search-term evidence. Do not automatically exclude free,
tutorial, or non-economic-buyer roles. Label competitiveness estimates as
hypotheses unless backed by current platform data.

Record persistence_enabled explicitly. If false, keep source cards and
final creative attribution in memory for this run; Step 3C must not read or
write a file. If true, store immutable versions by verified workspace ID,
not name alone; retain display slugs as labels. Update final attribution
only in the current version, without rewriting versions used by predictions.
