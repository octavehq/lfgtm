# deck: task method

### QBR, renewal, and value-review branch

Read the CRM opportunity/account and the relevant prior-review, success-plan, and renewal calls. Extract the review period, agreed goals, commitments, owners, reported outcomes, unresolved risks, and next decision. Match each goal to its current evidence: measured result, buyer-reported result, modeled benefit, or not yet measured.

Request only missing measures needed for this review. Example: “The last review targeted adoption by three teams. Please provide this quarter's active teams/users and relevant feature usage for that period, plus any measured outcome absent from the calls.” Ask for a value assessment or POC result when it is necessary; do not assume CRM access includes telemetry. Continue the draft, incorporate the response, and recheck figures.

Use this sequence: decision/period summary → goals versus results → value and adoption evidence → gaps/risks → mutual plan with owners, dates, and success measures. A renewal adds unresolved obligations and renewal decisions. An intentional future-measurement field belongs in the forward plan. Do not present it as an achieved result.

For every slide, retain an internal claim ledger: claim, source ID or operator input, date/period, unit/denominator, evidence status, relevant offering/buyer, external-use status, and any qualifier needed on the slide or in notes. One source list for the whole deck does not replace this ledger.

Resolve available export tooling before offering an automated route. PDF must contain one page per slide; editable PPTX must preserve every slide's text, images, chart meaning, and notes, with explicit fidelity limits. A raster-slide PPTX is a separate, noneditable option. Use a tested exporter when installed; otherwise provide a clearly labeled manual handoff and do not say the export is complete. Google Slides upload/import is complete only after native readback; without that capability, label the remaining import step. Package HTML with its referenced assets or embed them. Validate exported slide/page counts, text coverage, image presence, and rendered fit. Keep platform-specific carousel limits in dated documentation and verify current limits before enforcing them.
