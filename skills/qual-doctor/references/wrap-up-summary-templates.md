# Qualification tuning summary

Report diagnostic and held-out results separately: case counts, labels/thresholds, routed accuracy, section separation, false positives/negatives, unknown-evidence rate, and subgroup regressions. Small samples are exploratory.

Distinguish recommended changes, verified applied changes, no-op/partial writes, and pending checks. Show protected/shared-agent checks and recovery state. Report measured usage only if returned; otherwise identify estimates and unknown costs.
